# 홈 아키텍처

- 요구사항: HOME-01. 책임: 반려동물·물그릇·화장실과 최근 기록 조회.
- 현재 상태: 로그인 후 승인된 가족을 선택하고 그룹별 Firestore 목록과 최근 기록을 표시한다. 빈 상태·실패 재시도·관리 화면 및 대상별 기준·기록 진입을 제공한다. 당일 요약 집계와 가족 전환 UX 개선은 남아 있다.

## 흐름과 계층

화면은 사용자 입력을 BLoC/Cubit에 전달하고 로딩·성공·빈 상태·실패를 렌더링한다. 일회성 이동과 메시지는 지속 상태와 분리한다. Domain은 엔티티·유스케이스·저장소 계약을 소유하고, data는 DTO·데이터 소스·저장소 구현을 제공한다. 앱 조립 계층이 구현을 주입한다.

## 데이터와 연동

- 의존성: 각 feature의 공개 조회 계약.
- JSON은 data 경계에서 DTO로 검증하고 도메인 모델로 변환한다. 공통 오류는 실패 타입으로 변환한다.
- 공유 데이터와 사진은 가족 그룹을 기준으로 분리하며 실제 서버에서 권한을 검증한다.
- 테스트에는 가짜 저장소와 고정 상태를 사용한다. 네트워크·플랫폼 플러그인을 Preview에서 호출하지 않는다.

## 검증 및 결정 대기

- 정상·빈 상태·실패·재시도와 권한 거부를 테스트한다. 입력·삭제·중복·그룹 격리는 해당 기능 구현 시 추가한다.
- 선행 결정: 그룹 시간대 및 기록 집계. 실제 연동 전에 계약과 수용 기준을 구체화한다.
- 설계 변경 시 PRD 요구사항과 상태·인터페이스·테스트를 함께 갱신한다.

## 기능별 설계 상세

- 화면 흐름: 그룹 선택 → 반려동물·대상·최근 기록 확인 → 등록 또는 상세 이동.
- 상태·계약: 홈은 기존 PetCubit, WaterBowlCubit, LitterBoxCubit의 로딩·빈 데이터·성공·실패를 구독한다. 해당 feature의 상세 진입 함수를 사용한다.
- 필수 테스트: 다른 그룹 캐시 혼입, 미수집·0·실패 구분과 날짜 경계.
- 잔여 작업: 실제 가족 그룹 선택 및 데이터 격리, 그룹 시간대 기반 당일 기록, Firebase 저장소와 실제 로그인 연결. 현재 임시 그룹의 메모리 데이터만 표시하며 집계를 만들지 않는다.
