# 하릅 테스트 케이스

기준: [PRD v0.4](PRD.md). 아래는 요구사항 기반 수동 테스트 초안이며, 통과 결과나 구현 완료를 의미하지 않는다. Android와 iOS에서 각각 실행하고 빌드 버전, 기기, 실행일, 결과 및 결함 링크를 별도로 기록한다. P0는 출시 전 필수 검증, P1은 주요 기능 검증이다. 미구현 기능이나 외부 연동이 준비되지 않은 경우 **차단**으로 기록한다.

## 공통 준비

- 가족 A의 관리자와 일반 구성원, 가족 B의 계정 및 승인 대기 계정을 준비한다. 가족별 데이터가 서로 다르게 보이도록 반려동물과 기록을 준비한다.
- 카메라·사진 접근 권한 허용/거부, 네트워크 연결/차단, 정상·손상·저화질 사진을 재현할 수 있는 기기를 준비한다.
- 분석 결과가 필요한 케이스는 실제 연동 환경 또는 결과와 실패를 제어할 수 있는 테스트 환경에서 실행한다. 검증되지 않은 분석 수치가 실제 사용자에게 노출되지 않는지도 확인한다.

## 실행 현황 (2026-10-29)

- 프로젝트 지정 Flutter 3.47.8 / Dart 3.13.7에서 `flutter analyze` 통과.
- 같은 SDK의 자동화 테스트: 36개 통과, 10개 실패. 여러 위젯 테스트는 `ink_sparkle.frag` 셰이더 검증 오류로 실패했고, 기존 앱 스모크 테스트는 `반려동물 관리` 위젯을 찾지 못했다. 셰이더 오류는 서로 다른 Flutter SDK가 생성물을 공유한 영향일 가능성이 있어 원인 확인이 필요하다.
- 위 결과는 자동화 테스트 결과이며 이 문서의 수동 TC 통과를 뜻하지 않는다. Android/iOS 기기별 수동 실행 및 Firebase 계정·연동이 필요한 시나리오는 아직 실행하지 않았다.
