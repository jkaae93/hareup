# 하릅(Hareup) 제품 요구사항 정의서

- 문서 상태: 사진 분석 기반 개정 초안 v0.4
- 개정일: 2026-10-28
- 대상 플랫폼: Flutter 기반 Android / iOS
- 기존 디자인 참고: [hareup-all-design.pdf](../design/hareup-all-design.pdf). 기기 중심 화면은 이번 요구사항에 맞춰 재설계가 필요하다.
- 구현 현황: Flutter 앱 구조, 이메일 인증, 가족 승인 흐름, 그룹별 Firestore/Storage 저장과 사진 분석 callable은 구현했다. Firebase 배포·통합 검증과 분석 정확도 검증은 미완료이며, 검증 전 결과 표시를 차단한다.
- 승인 상태: 제품 정책, 분석 성능 및 출시 기준 승인 전

## 1. 제품 개요

하릅은 반려동물 보호자가 물그릇과 고양이 화장실의 사진을 등록하고 이후 사진과 비교하여 음수 및 배변 변화를 확인하는 모바일 앱이다. 별도의 정수기, 센서 또는 연결 기기를 사용하지 않는다. 기존 디자인의 기기 등록·연결·상태·구매 기능은 이번 제품 범위에서 제외한다.

물그릇은 고양이와 강아지를 지원한다. 화장실 분석은 일반 고양이 화장실을 대상으로 하며 자동화장실은 제외한다. 사진 분석 결과는 추정 및 관찰 정보이며 질병을 확진하거나 치료를 지시하지 않는다.

### 목표와 사용자 가치

- 보호자가 가득 찬 물그릇을 기준 사진으로 등록하고 이후 물 감소량을 확인한다.
- 보호자가 깨끗한 고양이 화장실을 기준 사진으로 등록하고 이후 소변·대변의 관찰 횟수와 상태를 확인한다.
- 선택 입력값이 충분하고 분석 신뢰도를 확보한 경우 물과 배설물의 추정량을 제공한다.
- 가족이 같은 반려동물과 기록을 함께 확인한다.

## 2. 범위와 핵심 흐름

### MVP 범위

로그인, 반려동물 관리, 물그릇 및 일반 고양이 화장실 등록, 사진 업로드·분석, 분석 결과 확인·수정 및 기록 조회, 가족 공유를 제공한다. 사진 촬영은 휴대전화 카메라 또는 사진 보관함을 이용한다.

```text
로그인 → 반려동물 등록 → 물그릇 등록 → 가득 찬 기준 사진 등록
  → 물이 줄어든 사진 등록 → 비교 분석 → 결과 확인·기록
로그인 → 고양이 등록 → 일반 화장실 등록 → 깨끗한 기준 사진 등록
  → 소변·대변 사진 등록 → 비교 분석 → 횟수·상태·가능한 경우 추정량 확인
홈 → 반려동물·물그릇·화장실 선택 → 기록 조회
회원 가입 → 가족 초대 코드 입력 → 관리자 승인 대기 → 승인 후 공유 기록 조회
```

### 제외 범위

- 기기 연결, 센서 측정, 원격 제어, 펌웨어 및 기기 구매.
- 자동화장실 분석, 사진을 이용한 개별 반려동물 자동 식별.
- 질병 확진, 치료·약물 지시, 권장 음수량 처방.
- 검증되지 않은 사진 기반 정밀 계량이나 실시간 상시 감시.

## 3. 공통 등록과 사진 분석

### PET-01. 반려동물 관리

- 고양이 또는 강아지의 이름을 등록하고 사진, 나이, 성별, 체중 및 질환 정보는 선택적으로 입력한다. 질환 선택지는 별도 확정한다.
- 프로필 수정·삭제를 제공하며 삭제 시 기록에 미치는 영향을 안내한다.
- **수용 기준:** 종류와 유효한 이름을 입력하면 저장 후 목록에 반영된다. 선택 사진 접근을 거부해도 기본 이미지로 등록할 수 있다. 삭제 취소 또는 실패 시 기존 데이터가 유지된다.

### PHOTO-01. 사진 입력 및 비교

- 기준 사진과 후속 사진을 촬영하거나 선택한다. 동일한 위치·각도·거리와 충분한 조명, 전체 그릇 또는 화장실이 보이는 구도를 안내한다.
- 사진 분석 제공자 방향은 Meta AI다. Firebase 프로젝트 외에 분석 백엔드/API 계약도 아직 없으므로, MVP 연결 전 이미지 입력 지원 모델·응답 스키마·데이터 처리 조건을 확인한다. 앱에 공급자 비밀키를 넣지 않고 서버 경유로 호출한다. Meta 모델의 이미지 인식 지원은 제품의 관찰 정확도를 보장하지 않으므로 별도 데이터 검증과 출시 승인이 필요하다.
- 기준 사진과 비교가 어렵거나 가려짐, 반사, 그림자, 낮은 해상도 등으로 판독이 어려우면 결과를 만들어내지 않고 이유와 재촬영 방법을 안내한다.
- 분석 중, 완료, 분석 불가, 업로드 실패를 구분하고 재시도를 제공한다. 사용자는 저장 전에 결과를 확인하고 잘못된 관찰 횟수를 수정할 수 있다. 수정 결과와 원래 추정 결과는 구분해 저장한다.
- 물 보충·교체, 그릇 변경, 모래 교체·청소 등으로 기준이 달라진 경우 새 기준 사진을 등록한다. 이전 기록은 당시 기준에 연결해 유지한다. 기준 변경 전후를 자동으로 연속 합산하지 않는다.
- **수용 기준:** 기준 사진이 없으면 비교 분석을 시작하지 않는다. 비교 불가 사진에는 수치나 정상 판정을 표시하지 않는다. 중복 제출이나 재시도로 같은 기록이 중복 생성되지 않는다.

## 4. 물그릇 분석

### WATER-01. 물그릇과 기준 등록

- 물그릇 이름과 가득 찬 상태의 사진을 등록하고, 사용하는 반려동물을 연결한다. 여러 반려동물이 함께 사용하는 그릇도 등록할 수 있다.
- 빈 그릇의 무게(g)와 가득 채웠을 때 물의 양(mL)을 각각 선택 입력한다. 입력한 값은 0보다 커야 하며 물의 양은 그릇 무게를 제외한 값으로 안내한다.
- **수용 기준:** 두 선택값이 없어도 기준 사진을 저장할 수 있다. 어느 하나만 입력했을 때도 저장할 수 있지만 mL 추정 조건이 충족되지 않았음을 안내한다. 기준 사진의 변경은 기존 분석 결과를 덮어쓰지 않는다.

### WATER-02. 물 감소 분석과 결과

- 후속 사진에서 물의 상태를 기준 사진과 비교해 기준 대비 물이 줄어든 비율을 추정한다. 결과에 비교 시각, 기준 사진, 후속 사진 및 ‘추정’ 표시를 제공한다.
- 그릇 무게와 가득 찬 물의 양을 **모두 입력**하고 해당 그릇·사진에 대해 부피 추정이 검증된 경우, 감소 비율과 추정 감소량(mL)을 표시한다. 물 감소량은 음수량의 추정치로 안내한다.
- 두 값 중 하나라도 입력하지 않았다면 감소 비율(%)만 표시한다. 물 보충, 증발, 쏟음 및 여러 반려동물의 공동 사용이 감소량에 영향을 줄 수 있으므로 개별 반려동물이 마신 양으로 단정하지 않는다.
- 그릇의 무게만으로 사진 속 수위나 물의 부피를 계산할 수 없다. 그릇의 형태와 수위에 따른 부피 관계를 확인할 수 없거나 추정 정확도가 검증되지 않으면 mL를 표시하지 않고 그 이유를 안내한다. 단순히 수위 감소율에 가득 찬 용량을 곱해 모든 그릇의 부피 감소율로 취급하지 않는다.
- 이전 사진 대비 음수 추세나 기간 합산은 보충·교체 여부와 비교 구간을 확인할 수 있을 때만 제공한다. 반복 촬영의 누적 감소량을 중복 합산하지 않는다.
- **수용 기준:** 선택값 미입력 시 %만 표시한다. 두 값을 입력해도 부피 추정이 불가능하면 mL를 표시하지 않는다. 공동 사용 그릇의 결과는 그릇 단위로 표시한다. 물 높이가 기준보다 높거나 보충이 의심되면 음수량으로 계산하지 않고 기준 갱신 또는 재촬영을 안내한다.

## 5. 고양이 화장실 분석

### LITTER-01. 화장실과 기준 등록

- 일반 고양이 화장실의 이름과 깨끗한 모래 상태 사진을 등록하고 사용하는 고양이를 연결한다. 자동화장실은 지원하지 않음을 등록 시 안내한다.
- 화장실의 내부 가로·세로 길이와 모래 높이를 선택 입력한다. 각각 양수와 단위(cm)를 사용한다. 해당 값 없이도 등록할 수 있다.
- 청소 또는 모래 교체 후 깨끗한 사진을 새 기준으로 등록할 수 있다. 기준이 바뀐 시각을 저장한다.
- **수용 기준:** 선택값 없이 기준 등록이 가능하다. 자동화장실은 분석 대상으로 등록할 수 없다. 불완전한 치수 입력은 저장하되 추정량 제공 조건이 충족되지 않았음을 안내한다.

### LITTER-02. 소변·대변 분석

- 후속 사진과 깨끗한 기준 사진을 비교하여 눈에 보이는 소변 흔적과 대변을 구분하고 각각의 관찰 횟수를 추정한다. 사용자가 확인·수정할 수 있다.
- 횟수는 사진에서 구별 가능한 흔적의 추정 수로 표시한다. 겹치거나 묻힌 흔적, 하나로 뭉친 여러 배뇨, 나뉜 하나의 대변 등은 실제 배변 횟수와 다를 수 있다. 식별이 어려우면 불확실함을 알리고 확인을 요청한다.
- 화장실 크기와 모래 높이가 **모두 입력**되고 분석 방법이 검증된 경우 소변·대변의 관찰량을 추정해 표시한다. 치수가 없거나 일부만 있으면 소변·대변 횟수만 표시한다. 크기와 모래 높이만으로 실제 소변량이나 대변 중량을 보장할 수 없으므로 검증된 단위와 방법이 없거나 사진으로 산출할 수 없으면 추정량을 표시하지 않는다.
- 공유 화장실에서는 특정 고양이에게 자동 귀속하지 않는다. 보호자가 알고 있는 경우에만 대상 고양이를 선택할 수 있으며, 모르면 미확인으로 저장한다.
- 청소하지 않은 상태에서 반복 촬영하면 이전에 관찰한 흔적을 새 배변으로 중복 집계하지 않도록 비교 구간을 명시한다. 구분이 불가능하면 신규 횟수를 확정하지 않고 사용자 확인을 요청한다.
- **수용 기준:** 치수 및 모래 높이가 없으면 횟수만 표시한다. 모든 입력이 있어도 신뢰할 만한 추정이 불가능하면 추정량을 표시하지 않는다. 소변과 대변을 각각 확인·수정할 수 있고 확인되지 않은 대상을 특정 고양이에게 배정하지 않는다.

### HEALTH-01. 관찰 상태와 건강 안내

- 사진에서 관찰 가능한 대변의 형태·상태와 소변 흔적의 색을 표시하고, 관찰 결과에 관련된 건강 정보를 제공한다. 모래 색, 조명, 사진 품질 및 가림에 따라 판단이 어려울 수 있음을 안내한다.
- 이상 가능성이 보이면 진단명으로 확정하지 않고 수의사 상담을 권고한다. 소변을 보려고 반복해서 힘주지만 나오지 않는 등 사용자가 확인한 응급 증상에 대해서는 즉시 수의 진료를 안내한다. 사진만으로 해당 증상의 유무를 판단하지 않는다.
- 색이나 상태를 판독할 수 없으면 ‘판독 어려움’으로 표시하며 정상·이상 없음을 주장하지 않는다. 안내 문구, 위험 신호와 검증 기준은 수의 전문가 검토 후 출시한다.
- **수용 기준:** 관찰 내용과 건강 관련 안내를 구분한다. 품질이 부족한 사진에 건강 판정을 제공하지 않는다. 결과 화면에 추정 정보이며 진단이 아니라는 설명과 상담 권고를 제공한다.

## 6. 홈, 기록과 가족 공유

### HOME-01. 홈 및 기록

- 반려동물과 등록된 물그릇·화장실을 표시하고 사진 등록과 최근 기록 조회로 이동한다. 빈 상태에서는 해당 등록 흐름을 안내한다.
- 기록에는 대상, 기준 사진의 버전, 촬영·분석 시각, 결과의 단위와 추정 여부를 표시한다. 결과 없음, 분석 불가, 실제 0을 구분한다.
- 당일 기록은 선택한 가족 그룹의 시간대 기준으로 표시한다. 물 감소율, 물 추정량, 배설 횟수와 추정량은 서로 다른 단위로 분리한다.
- **수용 기준:** 기록과 원본 결과가 일치하고 다른 가족 그룹의 기록이 섞이지 않는다. 여러 사진이 같은 누적 변화를 나타내는 경우 단순 합산하지 않는다.

### AUTH-01 및 FAM-01. 로그인·가족

- 회원 가입 후 가족 관리에서 초대 코드를 입력해 가입을 요청한다. 관리자가 승인한 뒤에만 해당 가족 데이터에 접근할 수 있다. 가입 요청과 승인 상태를 화면에 표시한다.
- 관리자는 초대 코드를 만들고 가입 요청을 승인하며 구성원을 삭제할 수 있다. 관리자 외 구성원도 가족 데이터의 추가·수정은 할 수 있지만 삭제할 수 없다. 이 권한은 서버에서 매 요청마다 검증한다.
- 구현 임시 정책: 초대 코드는 7일 뒤 만료되고, 새 코드 발급 시 이전 코드를 무효화한다. 만료·교체 전 유효 코드는 여러 가입 요청에 재사용할 수 있다. 이 값은 제품 확정 전이므로 출시 전에 검토한다.
- 미결정: 관리자 변경·탈퇴 정책, 가족 데이터의 생성자 소유권, 복수 가족 가입 및 가입 요청 거절·재요청 흐름.
- **수용 기준:** 인증 실패 시 재시도할 수 있다. 코드 입력만으로 데이터 접근을 허용하지 않고 관리자 승인 전에는 그룹 데이터 접근이 차단된다. 관리자만 삭제 및 승인할 수 있고, 구성원 제거 후 서버 요청과 로컬 캐시에서 접근이 회수된다.

사진·분석 결과는 해당 가족의 권한 있는 사용자에게만 제공한다. 사진 업로드 및 처리에 필요한 권한을 요청하고, 원본·결과·캐시·백업의 보관 기간과 삭제 정책, 외부 분석 서비스 이용 및 데이터 사용 범위는 출시 전에 확정·고지한다. 분석 이벤트에는 사진 원본, 질환 정보, 이메일 또는 인증 토큰을 포함하지 않는다.

## 8. 품질 및 분석 검증

- 분석 모델과 산출 방식, 지원하는 그릇 형태·화장실·모래 종류, 사진 촬영 조건을 정하고 대표적인 조건에서 검증한다. 실제 측정값 및 보호자 확인 횟수와 비교하여 오차와 판독 불가율을 평가한다.
- 물 감소 %와 mL, 배설 횟수와 추정량, 대변 상태와 소변 색은 각각 별도로 검증한다. 정확도 목표와 최소 표본, 허용 오차, 불확실 시 표시 정책은 제품·기술·수의 전문가가 출시 전에 승인한다. 검증되지 않은 수치는 노출하지 않는다.
- 카메라·사진 권한 거부, 업로드 중단, 네트워크 오류, 사진 손상 및 분석 실패 시 입력을 가능한 범위에서 유지하고 복구 방법을 제공한다.
- 색상만으로 결과를 전달하지 않으며 화면 읽기와 확대 글꼴을 지원한다. 날짜와 단위를 명확히 표시한다.
- Android/iOS에서 핵심 흐름, 가족 간 접근 격리, 기록 중복 및 기준 변경을 검증한다. `flutter analyze`와 `flutter test`를 통과해야 한다.

## 10. 성공 지표 [제안]

기준선과 수치 목표는 아직 확정되지 않았다. 기준 사진 등록 완료율, 후속 사진 분석 완료율, 분석 불가율, 결과 수정률, 4주차 기록 이용률을 물그릇과 화장실별로 측정한다. 분석 완료율과 실제 정확도는 별도로 평가한다. 계측에는 가명 식별자를 사용하고 테스트 계정과 중복 요청을 제외한다.
